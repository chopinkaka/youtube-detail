설치와 업데이트

  1. ZIP을 풀고 START.bat를 실행하세요. 처음 실행할 때 필요한 패키지를 설치합니다.
  2. 핵심 노트를 자동 생성하려면 본인의 Gemini API 키를 앱에 입력하세요.
  3. 첫 실행에서 자동 업데이트를 켜면, 다음부터는 실행할 때 최신 버전을 받습니다. 기존 작업은 같은 폴더에서 계속 열 수 있습니다.
